# Северный шторм — изображения

Все шесть обязательных изображений сохранены в размерах манифеста. PNG содержат настоящий альфа-канал. Иконка экспортирована в 256, 128, 64, 48, 44, 32 и 16 px; icon.ico содержит шесть размеров Windows. В vite-src/public заменён icon.png и добавлен icon.ico.

Изображения созданы встроенным image_gen. Топор выполнен в SVG и экспортирован в одноцветный белый PNG. Промпты — PROMPTS.md, размеры, альфа-каналы и измерение контраста — validation.json.

Фон дополнительно отредактирован: яркие звёзды убраны с левой половины для читаемости заголовка. Композиция генератора отличается от схемы: основной пик смещён вправо примерно до 75% ширины.

Дополнительные dock-texture.webp и play-metal.webp приложены как варианты. Для dock-texture бесшовность и допуск яркости ±4% не подтверждены; использовать как экспериментальную фактуру. Слои параллакса и спрайт-лист не создавались, покачивание корабля предполагается через CSS.

Изображения сцены подготовлены для подключения при вёрстке нового оформления; текущая вёрстка лаунчера не менялась.
